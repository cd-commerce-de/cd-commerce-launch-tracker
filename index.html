Target shows the Good threshold for that specific week — Sales Price, Units, Avg. CPC, Avg. CR, and Organic Sales % come straight from your weekly forecast upload; every other row is calculated from those 5, the same way the template does it. Each week's Actual cell is colored by which tier that week hit: red below Good, yellow Good to Better, green Better to Best, gold above Best. Rows show "–" for any week with no forecast uploaded yet. Metrics Glossary

Every metric in this dashboard, split into two groups: taken directly from your Sellerboard/Sellerfox uploads (never calculated, shows "N/A" if the source file doesn't report it for that week), and calculated from those direct values.

Taken directly from the export

These never get computed, approximated, or defaulted to zero. If the underlying export doesn't report a value for a given week, the cell shows "N/A" rather than guessing.

MetricSourceNotes
Total Sales (€)Sellerboard — "Sales" columnN/A if that week's row doesn't report Sales
Units SoldSellerboard — "Units" columnN/A if that week's row doesn't report Units
Refund UnitsSellerboard — "Refunds" columnN/A if that week's row doesn't report Refunds
Ad Spend (€)Sellerboard — "Ads" columnStored as a positive number regardless of sign in the export. N/A if not reported.
Net Profit (€)Sellerboard — "Net profit" columnN/A if that week's row doesn't report Net profit
SessionsSellerfox — "Sessions" columnN/A if Sellerfox wasn't uploaded for that week, or didn't report it. Sellerboard's own Sessions column is not used, even when present, since it measures/aggregates this differently.
ImpressionsSellerfox — "Impressions (SP)" columnN/A if Sellerfox wasn't uploaded for that week, or didn't report it
Ad ClicksSellerfox — "Clicks (SP)" columnN/A if Sellerfox wasn't uploaded for that week, or didn't report it
Ad OrdersSellerfox — "Units 7D Same (SP)" columnSellerfox's own export doesn't have a literal "Ad Orders" column — this is the closest real field (same-SKU, ad-attributed units over a 7-day window). "Units 7D (SP)" without "Same" was deliberately not used, since it includes halo/cross-sell units for other products bought after this product's ad was clicked. N/A if Sellerfox wasn't uploaded.
Ad Sales (€)Sellerfox — "Sales 7D (SP)" columnNo "Same SKU" variant exists for Sales the way it does for Units, so this may include some halo/cross-sell sales attributed to other products. N/A if Sellerfox wasn't uploaded.
Organic Sales (€) / Organic Sales (%)Not available from either exportAlways shows N/A. Total Sales − Ad Sales was considered and deliberately rejected — even though both pieces are real numbers, subtracting them is still a calculation, and this metric is meant to be a direct figure or nothing.

Calculated from the values above

Metric names below match exactly what's shown on the dashboard. Any calculation involving a metric from the table above inherits its N/A behavior — e.g. if Ad Spend is N/A for a week, TACoS is N/A for that week too, not silently treated as based on €0.

MetricFormulaNotes
Refund Rate (%)Refund Units ÷ Units SoldUses Sellerboard's own reported Refund % first if available; this formula is only the fallback
Margin (%)Net Profit ÷ Total SalesUses Sellerboard's own reported Margin % first if available; this formula is only the fallback. Totals/aggregates always use this formula (sales-weighted), never Sellerboard's raw per-week number.
ROI (%)Sellerboard's own reported ROI %, averaged across weeksNot independently recalculated — no fallback formula, N/A if Sellerboard doesn't report it
Real ACOS (%)Sellerboard's own reported Real ACOS %, averaged across weeksNot independently recalculated — no fallback formula, N/A if Sellerboard doesn't report it
TACoS (%)Ad Spend ÷ Total SalesAlways calculated, never pulled from either source directly
Cost Per Order (€)Ad Spend ÷ Units Sold
Profit Per Order (€)Net Profit ÷ Units Sold
Conversion Rate (%)Units Sold ÷ SessionsUses Sellerboard's own reported Unit Session % first if available; this formula is only the fallback
Click-Through Rate (%)Ad Clicks ÷ Impressions
Avg. CPC (€)Ad Spend ÷ Ad ClicksAd Spend from Sellerboard, Ad Clicks from Sellerfox
Average Sales Price (€)Sellerboard's own reported Average Sales Price, averaged across weeksNot independently recalculated from Sales ÷ Units
Refund Rate (%) — totals/aggregatesTotal Refund Units ÷ Total Units SoldUsed in Overview, Launch/Expansion Dashboard, and Portfolio Total
Margin (%) — totals/aggregatesTotal Net Profit ÷ Total SalesSales-weighted — a €50,000 week counts more than a €500 week
TACoS (%) — totals/aggregatesTotal Ad Spend ÷ Total Sales
Avg. Margin — Overview / Child SKU Summary rowSimple average of that product's weekly Margin % valuesNot sales-weighted — can differ slightly from Total Net Profit ÷ Total Sales for the same product

12-Wk Avg columnSimple averageMargin, ROI, Real ACOS, TACoS, Cost Per Order, Profit Per Order, Avg. CPC, Organic Sales %, Conversion Rate, Click-Through Rate, Average Sales Price
